# OmniAI site asset sources

The website runs entirely from local files. External URLs below are provenance only.

## Product assets

- `omniai.png`: local OmniAI application icon from `OmniAi-0.4/src/assets/OmniAi.iconset/`.
- `model-home-claude.webp`: Claude official product homepage, `https://www.anthropic.com/claude`.
- `model-home-chatgpt.webp`: ChatGPT official overview homepage, `https://chatgpt.com/overview`.
- `model-home-gemini.webp`: Gemini official app homepage, `https://gemini.google/`.
- `model-home-flow.webp`: Google Flow official product homepage, `https://labs.google/fx/zh/tools/flow`.
- `model-home-manus.webp`: Manus official homepage, `https://manus.im/`.
- `model-home-perplexity.webp`: Perplexity official brand mark from the registered service identity; the homepage was protected by a Cloudflare interstitial during capture, `https://www.perplexity.ai/`.
- `model-home-deepseek.webp`: DeepSeek official homepage, `https://www.deepseek.com/`.
- `model-home-glm.webp`: Zhipu Qingyan official app homepage, `https://chatglm.cn/`.
- `model-home-doubao.webp`: Doubao official app homepage, `https://www.doubao.com/`.
- `model-home-minimax.webp`: MiniMax official homepage, `https://www.minimax.io/`.
- `model-home-kimi.webp`: Kimi official app homepage, `https://www.kimi.com/`.
- `model-home-wenxin.webp`: Baidu Wenxin official app homepage, `https://yiyan.baidu.com/`.
- `model-home-qwen.webp`: Qwen official product landing page first-screen screenshot, `https://qianwen.aliyun.com/landing?family=qwen`.
- `model-home-jimeng.webp`: Jimeng official homepage first-screen visual, `https://jimeng.jianying.com`.
- `model-home-coze.webp`: Coze official overview first-screen visual, `https://www.coze.cn/overview`.

Homepage screenshots and official first-screen visuals were normalized to 960 x 600 and locally compressed to WebP for the model carousel.

## Workflow demo

- `image-output.webp`: local illustrative output from the Design Memory Google Labs carousel asset set. It represents an image-generation handoff in the product demo; it is not presented as a benchmark sample.
- `flow.webp`: local Google Flow Music promotional image from the same verified Design Memory component asset set.

## Fonts

- `MiSans-*.woff2` and `Outfit.ttf`: copied from the local Design Memory font library for offline use.
